# Campus Connect

Campus Connect is a web-based campus community project designed to help students discover and explore activities and events happening on their campus.

## About the Project

Campus Connect provides a simple interface for students to explore their campus community. The current project includes a home page and an events page containing upcoming technology, cultural and sports events.

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Current Features

- Responsive navigation interface
- Campus Connect landing page
- Events page
- Upcoming event cards
- Technology, cultural and sports event categories
- Event information including date, venue and description
